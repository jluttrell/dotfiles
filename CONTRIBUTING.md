# Contributing

This repository tracks my personal Mac configuration rather than a supported starter template. It is public for reference, but feature requests and pull requests are not accepted because changes are driven by the setup I actively use.

Bug reports are useful when the declared configuration does not reproduce its documented behavior. Include the failing command, the relevant error output, the macOS version, and the Nix or Home Manager generation when applicable.

For a general-purpose starting point, use the original repository linked in the attribution section of `README.md`.
